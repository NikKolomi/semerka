# Семерка

Сбор российских номеров телефонов со страниц сайтов.

Приложение принимает список адресов, скачивает страницы на сервере и собирает номера из 11 цифр, которые начинаются на `+7`, `7` или `8`. В списке они приводятся к виду `7XXXXXXXXXX`. Результат можно скопировать или сохранить в CSV и XLS.

Если сайт не открылся или отдал заглушку, его можно отметить как нерабочий либо вставить текст уже открытой страницы. Для вкладки, которая открыта в браузере, есть скрипт консоли.

P.S. Приложение создано при помощи вайбкода
## Запуск

```bash
npm install
npm run dev
```
